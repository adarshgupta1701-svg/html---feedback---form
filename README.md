# 📝 Feedback Form

My first HTML project — a simple feedback form built while learning Full Stack Web Development.

## ✨ Features
- Name, Email, Message fields
- Rating (0–5) using radio buttons
- File upload option

## 🛠️ Tech Stack
- HTML only

## 🚀 How to use
1. Download the `index.html` file
2. Open it in your browser
